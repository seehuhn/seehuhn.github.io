Lecture 24 Power and Size by Simulation

This is the R session for week 8. The lectures this week have been about the Neyman–Pearson lemma and the likelihood-ratio tests. In this session we will see how these tests perform in practice. The R technique we will use here is the indicator average from lecture 12, where the indicator now marks the samples for which the test rejects. The written reference for this is in appendix B.

24.1 The Size of a Test by Simulation

The test we consider today is the one-sided zz-test from example 20.6, in the numerical setting of the example: we have n=25n=25 observations from N⁢(θ,σ2)N(\theta,\sigma^{2}) with known σ=2\sigma=2 and we want to test H0:θ=10H_{0}\colon\theta=10 against H1:θ>10H_{1}\colon\theta>10 at level α=0.05\alpha=0.05, i.e. we reject if and only if X¯>10.658\bar{X}>10.658. By definition 20.4, the power function β⁢(θ)=ℙθ⁢(X¯>10.658)\beta(\theta)=\mathbb{P}_{\theta}(\bar{X}>10.658) is a probability, and by proposition A.14 we can approximate this probability by the proportion of samples where the test rejects. As in lecture 12, we write a function which, for one run of the test, returns TRUE if the test rejects and FALSE otherwise. The command mean can then be used to get the proportion of rejections. Before you run the code, predict the value it prints. Will it be exactly 0.050.05? How far away from 0.050.05 would it have to be before you would suspect a mistake in the code?

n <- 25
sigma <- 2
theta0 <- 10
crit <- theta0 + qnorm(0.95) * sigma / sqrt(n)
z_reject <- function(theta) {
x <- rnorm(n, mean = theta, sd = sigma)
mean(x) > crit
}
set.seed(2026)
mean(replicate(10000, z_reject(theta0)))
## [1] 0.0523

The rejection rate under H0H_{0} is 0.05230.0523. This is the estimated size of the test in the sense of definition 20.5. The value is not exactly 0.050.05, and it should not be: as in lecture 12, the estimate has standard deviation 0.05⋅0.95/10000=0.0022\sqrt{0.05\cdot 0.95/10000}=0.0022. Thus, a value between 0.0460.046 and 0.0540.054 is what we expect for a correct test, while a value of 0.070.07 would point to an error in the code. Calling the same function with a value of θ\theta above θ0\theta_{0} gives the power at this point; for θ=10.5\theta=10.5 and θ=11\theta=11 the exact values are 0.3460.346 and 0.8040.804, from example 20.6.

24.2 The Power Curve

A single number is a poor summary of a test, so we now consider the power function over a grid of alternatives. Figure 24.1 shows the rejection rates on the grid of values from 99 to 1212 in steps of 0.10.1 for three level 0.050.05 tests: the one-sided zz-test from above, the two-sided zz-test from example 20.7 and the one-sided zz-test applied to the first 1212 observations only. The last test is wasteful, but it is a legal level 0.050.05 test. The script R/S24-power.R can be used to reproduce the figure. Before you look at the figure, predict how the two-sided test compares with the one-sided test. Is its rejection rate above or below that of the one-sided test for θ<10\theta<10? Is it above or below for θ>10\theta>10?

The line in the figure is the exact power function (20.1) of the one-sided test, and the filled circles lie on it. All three curves pass through 0.050.05 at θ0=10\theta_{0}=10, as required for level 0.050.05 tests, and the tests differ only in power. The two-sided test has lower power than the one-sided test for θ>10\theta>10 and much higher power for θ<10\theta<10. Thus, neither curve lies above the other everywhere, and this illustrates proposition 22.5. From example 22.3 and proposition 22.4 we know that no level 0.050.05 test based on these 2525 observations can reject at θ=11\theta=11 more than 80%80\% of the time. The crosses show the cost of having discarded thirteen of the observations: the power at θ=11\theta=11 decreases from 0.800.80 to 0.530.53.

24.3 Wilks’ Theorem in Action

Assume now that the variance is not known, so that the model has the two parameters θ\theta and σ2\sigma^{2}, and H0:θ=10H_{0}\colon\theta=10 leaves σ2\sigma^{2} free. By example 5.4, the log-likelihood is maximised over all parameters at σ^2=1n⁢∑i(Xi−X¯)2\hat{\sigma}^{2}=\frac{1}{n}\sum_{i}(X_{i}-\bar{X})^{2}, and the same computation with θ0\theta_{0} in place of X¯\bar{X} gives the maximum σ^02=1n⁢∑i(Xi−θ0)2\hat{\sigma}_{0}^{2}=\frac{1}{n}\sum_{i}(X_{i}-\theta_{0})^{2} under H0H_{0}. In both cases the maximised log-likelihood equals −n2⁢log⁡(2⁢π⁢σ^2)−n2-\frac{n}{2}\log(2\pi\hat{\sigma}^{2})-\frac{n}{2}, with σ^02\hat{\sigma}_{0}^{2} in place of σ^2\hat{\sigma}^{2} under H0H_{0}, and thus by (23.1) we find

W=n⁢log⁡∑i=1n(Xi−θ0)2∑i=1n(Xi−X¯)2.W=n\log\frac{\sum_{i=1}^{n}(X_{i}-\theta_{0})^{2}}{\sum_{i=1}^{n}(X_{i}-\bar{X% })^{2}}.

By Wilks’ theorem (theorem 23.3), with r=1r=1 as in lecture 23, the distribution of WW under H0H_{0} converges to χ12\chi^{2}_{1} as n→∞n\to\infty. In the case of known variance from lecture 23 the chi-squared distribution was exact, but here it is only an approximation, and we need to check how good it is for the nn we have. We simulate WW under H0H_{0} for n=10n=10 and n=100n=100, using σ=2\sigma=2 again, and we reject if WW exceeds the critical value 3.8413.841 of χ12\chi^{2}_{1}, as if the theorem were exact. Before you run the code, predict the two rejection rates. Will the rate for n=10n=10 be above or below 0.050.05?

wilks <- function(n) {
x <- rnorm(n, mean = theta0, sd = sigma)
n * log(sum((x - theta0)^2) / sum((x - mean(x))^2))
}
set.seed(2026)
w10 <- replicate(10000, wilks(10))
w100 <- replicate(10000, wilks(100))
crit_w <- qchisq(0.95, df = 1)
c(n10 = mean(w10 > crit_w), n100 = mean(w100 > crit_w))
## n10 n100
## 0.0745 0.0516

The rejection rate for n=100n=100 is 0.0520.052, which is within simulation error of the nominal level. The rejection rate for n=10n=10 is 0.0750.075: the test with nominal level 0.050.05 has type I errors half again as often as it should. Figure 24.2 shows why. In the quantile plots of the bottom row, made in the same way as the normal quantile plots of lecture 12, the points for n=10n=10 rise above the line from about 22 onwards, and thus the upper tail of WW is heavier than that of the limit.

The simulated values can also be used to find a threshold which does give size 0.050.05: the 0.950.95-quantile of the simulated WW.

unname(c(quantile(w10, 0.95), quantile(w100, 0.95)))
## [1] 4.654164 3.902230

For n=10n=10 the threshold needs to be about 4.654.65 instead of 3.843.84, while for n=100n=100 the two values are close enough that it does not matter which one is used. For this model the exact distribution is known: exercise 23.1 uses the tt distribution of appendix A to compare the two tests, and lecture 29 builds the exact test. In general, an asymptotic level is only guaranteed in the limit. An exact test should be used if one is available, and if not, a simulation under H0H_{0} can be used to determine the actual size at a given nn.

24.4 A Task to Take Home

The following task is in the style of a practical report. Set the seed of the random number generator to your student ID and consider the setting from section 24.2, but with sample size n=10n=10 instead of n=25n=25. Estimate the size of the one-sided zz-test for 1000010000 samples and state whether the estimated size is consistent with 0.050.05, within simulation error. Next, estimate the power of the test on the grid seq(9, 13, by = 0.1) and create a plot of the estimated power curve, together with the exact power function from lecture 20; the script R/S24-power.R shows how the command sapply can be used to apply the rejection-rate recipe to every point of a grid. From the plot, determine the smallest θ\theta at which the power is greater than 0.90.9. Finally, consider the test which rejects for large values of the sample median. Find its critical value first: simulate the median of 1010 observations under θ0=10\theta_{0}=10 and use the 0.950.95-quantile of the simulated values to get a test with size 0.050.05. (Using the critical value of the zz-test would lead to a much larger size, and comparing the power of two tests with different size is not meaningful.) Estimate the power curve of the calibrated median test and add it to your plot. Write a short paragraph comparing the two power curves, and use example 22.3 to explain why the median test cannot win.
