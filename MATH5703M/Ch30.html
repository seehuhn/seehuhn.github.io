Lecture 30 Do the Standard Tests Work?

This is the R session for week 10. We perform a tt-test for a real data set, and then consider two cases where a correct test can still be misleading: repeated testing, and data which violate the model assumption. As before, appendix B contains a written reference for the material covered in the session.

30.1 A Test on Real Data

The data set sleep, built into R, contains the amount of extra sleep (in hours) for ten patients, when treated with two different drugs. The two measurements for each patient are paired, and thus we can combine them into one difference as shown in the third row of table 29.1 and then perform a one-sample tt-test. The command t.test can be used to perform the test which example 29.2 performed manually.

d <- with(sleep, extra[group == 2] - extra[group == 1])
d
t.test(d)
## [1] 1.2 2.4 1.3 1.3 0.0 1.0 1.8 0.8 4.6 1.4
##
## One Sample t-test
##
## data: d
## t = 4.0621, df = 9, p-value = 0.002833
## alternative hypothesis: true mean is not equal to 0
## 95 percent confidence interval:
## 0.7001142 2.4598858

## mean of x

Every number in the output is one we know how to compute: the statistic t=10⋅1.58/1.23=4.06t=\sqrt{10}\cdot 1.58/1.23=4.06 is compared with the t9t_{9} distribution, the pp-value 0.00280.0028 is 2⁢ℙ⁢(T≥4.06)2\,\mathbb{P}(T\geq 4.06) as in definition 20.8, and the interval [0.70,2.46][0.70,2.46] is the tt-interval from example 25.4.

30.2 The Replication Crisis in Miniature

A test at level 0.050.05 has a 5%5\% chance of rejecting a true null hypothesis, which is harmless for one test but not when many tests are run and only the significant ones are reported. The number which matters is then the family-wise error rate, the probability that a study of mm tests reports at least one false discovery. We simulate studies of m=20m=20 tests, each a tt-test on a sample of size 2020 from N⁢(0,1)N(0,1), so that every null hypothesis is true. By lemma 20.9 each pp-value is uniform on (0,1)(0,1) under H0H_{0}, and since the tests are independent the family-wise error rate is 1−0.95201-0.95^{20}. Before you run the code, predict this value.

n <- 20
m <- 20
set.seed(2026)
study <- function() any(replicate(m, t.test(rnorm(n))$p.value) < 0.05)
mean(replicate(2000, study()))
1 - 0.95^m
## [1] 0.631
## [1] 0.6415141

Nearly two studies in three would find a significant result for nothing. The simplest remedy, the Bonferroni correction, is named here for reference but is not part of the module: it rejects only if p≤α/mp\leq\alpha/m. Since the probability of a union is at most the sum of the probabilities, the family-wise error rate is then at most m⋅α/m=αm\cdot\alpha/m=\alpha.

The same problem arises if one hypothesis is tested repeatedly instead of twenty hypotheses once each. The following function simulates a study where a sample of size 100100 is tested after every ten observations, and the procedure is stopped as soon as p<0.05p<0.05: this is the case of the researcher who “collects a few more data points and looks again”. Before you try the function, predict the rejection rate for this procedure under H0H_{0}.

peek <- function() {
x <- rnorm(100)
for (k in seq(10, 100, by = 10)) {
if (t.test(x[1:k])$p.value < 0.05) return(TRUE)
}
FALSE
}
mean(replicate(2000, peek()))
## [1] 0.206

Ten looks at the same data raise the type I error rate from 5%5\% to 21%21\%: each single test has level 0.050.05, but the procedure formed by choosing when to stop does not, and the reported pp-value takes no account of how the stopping time was chosen.

30.3 A Stress Test

Every test in table 29.1 assumes that the data are normally distributed. For distributions with heavy tails the central limit theorem takes effect only slowly, and section 17.5 lists further situations in which large-sample approximations are unreliable. We now try the tt-test on contaminated normal data, i.e. data which consist of N⁢(θ,1)N(\theta,1) with probability 0.950.95 and N⁢(θ,100)N(\theta,100) with probability 0.050.05. This could, for example, happen if one in twenty of the measurements is made using a faulty instrument. The resulting distribution is still symmetric around θ\theta and has variance 5.955.95. The function rcontam below can be used to generate such data, and the function decide can be used to obtain the decision of the tt-test at level 0.050.05 for one sample of size 2020.

rcontam <- function(n, theta, eps = 0.05) {
big <- rbinom(n, size = 1, prob = eps) == 1
theta + rnorm(n, sd = ifelse(big, 10, 1))
}
n <- 20
decide <- function(theta, contaminated) {
x <- if (contaminated) rcontam(n, theta) else rnorm(n, mean = theta)
t.test(x)$p.value < 0.05
}

We estimate the rejection rate for clean and for contaminated data from 50005000 samples each, at θ=0\theta=0 (the size) and at θ=0.5\theta=0.5 and θ=1\theta=1 (the power). Before you run the code, answer two questions. Does the size of the tt-test stay close to 0.050.05 under contamination? What happens to the power?

set.seed(2026)
rates <- sapply(c(0, 0.5, 1), function(theta) {
c(clean = mean(replicate(5000, decide(theta, FALSE))),
contaminated = mean(replicate(5000, decide(theta, TRUE))))
})
colnames(rates) <- c("theta = 0", "theta = 0.5", "theta = 1")
round(rates, 3)
## theta = 0 theta = 0.5 theta = 1
## clean 0.051 0.561 0.989
## contaminated 0.033 0.330 0.698

The first column shows that the tt-test keeps its level under contamination, and its size in fact decreases to 0.0330.033: a single ‘wild’ observation inflates SS more than it moves X¯\bar{X}, and thus the test statistic is reduced. The power columns tell a different story: for θ=1\theta=1 the tt-test rejects 99%99\% of the clean samples but only 70%70\% of the contaminated ones. The test still has the correct size, but fails to detect the effects present in the data; if the contamination were asymmetric, the size would change as well. As in lecture 24, when we are not sure about the model, we should simulate using a plausible alternative model, and should consider both the size and the power.
