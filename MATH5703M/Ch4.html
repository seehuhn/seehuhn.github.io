Lecture 4 Sufficiency

In example 4.2 we have observed ten coin tosses and got seven heads. Writing θ\theta for the heads probability, the likelihood in this example is L⁢(θ)=θ7⁢(1−θ)3L(\theta)=\theta^{7}(1-\theta)^{3}. This function depends on the data only via the number 77 of heads, but not on the order of heads and tails, i.e. for learning about θ\theta we can replace the full record of observations by this single number. This lecture makes the idea precise: a sufficient statistic contains all information about the parameter. The factorisation theorem helps to find sufficient statistics, and the concept of sufficiency forms the basis of improvements of estimators in lecture 6.

In this lecture we write X=(X1,…,Xn)X=(X_{1},\dots,X_{n}) for the data, x=(x1,…,xn)x=(x_{1},\dots,x_{n}) for an observed value, and

f⁢(x;θ)=∏i=1nf⁢(xi;θ)f(x;\theta)=\prod_{i=1}^{n}f(x_{i};\theta)

for the joint density or joint probability weights of the sample; the vector argument distinguishes it from the density of a single observation. As a function of θ\theta for fixed data, this is the likelihood L⁢(θ)L(\theta) from lecture 4.

4.1 Sufficient Statistics

A statistic T=T⁢(X1,…,Xn)T=T(X_{1},\dots,X_{n}) in the sense of definition 1.3 reduces the data to a smaller summary, and usually some information is lost in the process. The following definition expresses that no information about θ\theta is lost.

Definition 4.1.

A statistic T=T⁢(X1,…,Xn)T=T(X_{1},\dots,X_{n}) is sufficient for θ\theta, if the conditional distribution of (X1,…,Xn)(X_{1},\dots,X_{n}) given the value T=tT=t does not depend on θ\theta, for all values tt of TT.

If TT is sufficient, anyone who knows the value tt of TT can generate a new data set with the same distribution as the original data set, by sampling from the conditional distribution of XX given T=tT=t. Since this distribution does not depend on θ\theta, all information about θ\theta that we could obtain by studying the data set can now be obtained by studying tt alone.

Example 4.2.

Let X1,…,XnX_{1},\dots,X_{n} be i.i.d. Bernoulli with success probability pp and let T=∑i=1nXiT=\sum_{i=1}^{n}X_{i} be the number of successes. We know that T∼Binomial⁢(n,p)T\sim\text{Binomial}(n,p), as a sum of nn Bernoulli variables. Let t∈{0,1,…,n}t\in\{0,1,\dots,n\} and let x∈{0,1}nx\in\{0,1\}^{n} be a data vector with ∑ixi=t\sum_{i}x_{i}=t. Since the event {X=x}\{X=x\} is contained in the event {T=t}\{T=t\}, we have

ℙp⁢(X=x|T=t)=ℙp⁢(X=x)ℙp⁢(T=t)=pt⁢(1−p)n−t(nt)⁢pt⁢(1−p)n−t=1(nt).\mathbb{P}_{p}(X=x\mskip 1.0mu|\mskip 1.0muT=t)=\frac{\mathbb{P}_{p}(X=x)}{% \mathbb{P}_{p}(T=t)}=\frac{p^{t}(1-p)^{n-t}}{\binom{n}{t}p^{t}(1-p)^{n-t}}=% \frac{1}{\binom{n}{t}}.

If ∑ixi≠t\sum_{i}x_{i}\neq t, the events {X=x}\{X=x\} and {T=t}\{T=t\} are disjoint and the conditional probability is zero. In both cases the value does not depend on pp, and thus TT is sufficient for pp. Given the number of successes, each of the (nt)\binom{n}{t} possible arrangements of successes and failures is equally likely, whatever the value of pp: the positions of the successes do not contain any information about the coin.

Two simple observations follow from the definition. First, the whole sample T=(X1,…,Xn)T=(X_{1},\dots,X_{n}) is always sufficient, since given the whole sample there is no randomness left. Secondly, if φ\varphi is a one-to-one function, the events {φ⁢(T)=φ⁢(t)}\{\varphi(T)=\varphi(t)\} and {T=t}\{T=t\} coincide, and thus φ⁢(T)\varphi(T) is sufficient whenever TT is: a one-to-one function of a sufficient statistic is sufficient again. For the coin tosses the sample mean X¯=T/n\bar{X}=T/n is thus sufficient too.

4.2 The Factorisation Theorem

Directly verifying the definition of sufficiency requires knowledge of the distribution of TT and involves a conditional probability which, for most models, is tedious to compute. The following proposition replaces the computation with a condition on the density or weights.

Proposition 4.3 (Fisher–Neyman factorisation theorem).

The statistic TT is sufficient for θ\theta, if and only if there are functions hh and gg such that

equation (4.1) (4.1)
f⁢(x;θ)=h⁢(x)⁢g⁢(T⁢(x);θ)f(x;\theta)=h(x)\,g\bigl{(}T(x);\theta\bigr{)}

for all data vectors xx and all θ∈Θ\theta\in\Theta.

The function hh may not depend on θ\theta at all, and the function gg may depend on the data only through T⁢(x)T(x): the parameter and the data interact only through TT. Nothing in the statement requires TT or θ\theta to be one-dimensional. We give a proof for discrete data only.

Proof for discrete data.

Since we have discrete observations, the joint probability weight f⁢(x;θ)=ℙθ⁢(X=x)f(x;\theta)=\mathbb{P}_{\theta}(X=x) is the probability of observing the data vector xx.

Assume first that TT is sufficient and let xx be a data vector with t=T⁢(x)t=T(x). Since the event {X=x}\{X=x\} is contained in the event {T=t}\{T=t\}, we have

ℙθ⁢(X=x)=ℙθ⁢(X=x,T=t)=ℙθ⁢(X=x|T=t)⁢ℙθ⁢(T=t)\mathbb{P}_{\theta}(X=x)=\mathbb{P}_{\theta}(X=x,\,T=t)=\mathbb{P}_{\theta}(X=% x\mskip 1.0mu|\mskip 1.0muT=t)\,\mathbb{P}_{\theta}(T=t)

whenever ℙθ⁢(T=t)>0\mathbb{P}_{\theta}(T=t)>0. Using the sufficiency of the statistic, the conditional probability does not depend on θ\theta and thus is a function h⁢(x)h(x) of the data. The remaining factor is a function g⁢(t;θ)g(t;\theta) of tt and θ\theta. If ℙθ⁢(T=t)=0\mathbb{P}_{\theta}(T=t)=0 for the given θ\theta, both sides in (4.1) equal zero since g⁢(t;θ)=0g(t;\theta)=0. For the data vectors xx with ℙθ⁢(T=T⁢(x))=0\mathbb{P}_{\theta}(T=T(x))=0 for every θ\theta, which are never observed, we define h⁢(x)=0h(x)=0. Thus (4.1) holds for all xx and θ\theta.

Conversely, assume that (4.1) holds and let tt be a value of TT and θ\theta a parameter value with ℙθ⁢(T=t)>0\mathbb{P}_{\theta}(T=t)>0. Summing the factorisations for all data vectors yy with T⁢(y)=tT(y)=t, we find

ℙθ⁢(T=t)=∑y:T⁢(y)=tf⁢(y;θ)=∑y:T⁢(y)=th⁢(y)⁢g⁢(t;θ)=H⁢(t)⁢g⁢(t;θ),\mathbb{P}_{\theta}(T=t)=\sum_{y\colon T(y)=t}f(y;\theta)=\sum_{y\colon T(y)=t% }h(y)\,g(t;\theta)=H(t)\,g(t;\theta),

where H⁢(t)H(t) is the sum of the h⁢(y)h(y), which does not depend on θ\theta. Since the left-hand side is positive, we have g⁢(t;θ)≠0g(t;\theta)\neq 0. For data xx with T⁢(x)=tT(x)=t we get

ℙθ⁢(X=x|T=t)=ℙθ⁢(X=x)ℙθ⁢(T=t)=h⁢(x)⁢g⁢(t;θ)H⁢(t)⁢g⁢(t;θ)=h⁢(x)H⁢(t),\mathbb{P}_{\theta}(X=x\mskip 1.0mu|\mskip 1.0muT=t)=\frac{\mathbb{P}_{\theta}% (X=x)}{\mathbb{P}_{\theta}(T=t)}=\frac{h(x)\,g(t;\theta)}{H(t)\,g(t;\theta)}=% \frac{h(x)}{H(t)},

and for xx with T⁢(x)≠tT(x)\neq t the conditional probability is zero. Thus, in both cases the value does not depend on θ\theta and TT is sufficient. This completes the proof. ∎

The proof for the continuous case is more technical, and we omit it here. As a first step, one needs to define what it means to condition the distribution of XX on T=tT=t, since we typically have ℙ⁢(T=t)=0\mathbb{P}(T=t)=0 in the continuous case. To avoid these complications, we will use (4.1) as the definition of sufficiency for the continuous case from now on.

When the support depends on θ\theta, the density has to be written down for all xx, including the values where it is zero, since this is where the parameter and the data may interact. To write such densities compactly we use the indicator function of a condition, 𝟏{A}\mathbf{1}_{\{A\}}, which equals 11 if the condition AA holds and 0 otherwise. The uniform distribution is the standard example.

Example 4.4.

Let X1,…,Xn∼Uniform⁢(0,θ)X_{1},\dots,X_{n}\sim\text{Uniform}(0,\theta) be i.i.d. with θ>0\theta>0, as in example 1.2. The density of a single observation, written for all xi∈ℝx_{i}\in\mathbb{R}, is f⁢(xi;θ)=θ−1⁢𝟏{0≤xi≤θ}f(x_{i};\theta)=\theta^{-1}\mathbf{1}_{\{0\leq x_{i}\leq\theta\}}. A product of indicators is the indicator of the intersection of the conditions, and all nn conditions 0≤xi≤θ0\leq x_{i}\leq\theta hold if and only if the smallest observation is at least 0 and the largest is at most θ\theta. Thus the joint density is given by

f⁢(x;θ)=θ−n⁢∏i=1n𝟏{0≤xi≤θ}=𝟏{mini⁡xi≥0}⁢θ−n⁢ 1{maxi⁡xi≤θ}.f(x;\theta)=\theta^{-n}\prod_{i=1}^{n}\mathbf{1}_{\{0\leq x_{i}\leq\theta\}}=% \mathbf{1}_{\{\min_{i}x_{i}\geq 0\}}\;\theta^{-n}\,\mathbf{1}_{\{\max_{i}x_{i}% \leq\theta\}}.

If we set h⁢(x)=𝟏{mini⁡xi≥0}h(x)=\mathbf{1}_{\{\min_{i}x_{i}\geq 0\}} and g⁢(t;θ)=θ−n⁢𝟏{t≤θ}g(t;\theta)=\theta^{-n}\mathbf{1}_{\{t\leq\theta\}} we have

f⁢(x;θ)=h⁢(x)⁢g⁢(maxi⁡xi;θ)f(x;\theta)=h(x)g\bigl{(}\max_{i}x_{i};\,\theta\bigr{)}

and by proposition 4.3 the sample maximum X(n)=maxi⁡XiX_{(n)}=\max_{i}X_{i} is sufficient for θ\theta. It is a common mistake to try to write the joint density simply as θ−n\theta^{-n} and to conclude that no statistic is needed: the indicator is where the data and the parameter interact.

The factorisation has a consequence for maximum likelihood estimators. For fixed data the likelihood is L⁢(θ)=h⁢(x)⁢g⁢(T⁢(x);θ)L(\theta)=h(x)\,g\bigl{(}T(x);\theta\bigr{)}, and the factor h⁢(x)h(x) does not affect where the maximum over θ\theta is attained: the maximum likelihood estimator, whenever it is unique, is a function of any sufficient statistic. The examples of lecture 1 confirm this: the Bernoulli MLE is T/nT/n with the sufficient statistic TT of example 4.2, and the uniform MLE is the sample maximum, which example 4.4 shows to be sufficient.

4.3 Sufficiency in Exponential Families

For the exponential families from lecture 3, no work is needed to find a sufficient statistic, since the densities are already given in factorised form.

Corollary 4.5.

Let X1,…,XnX_{1},\dots,X_{n} be an i.i.d. sample from a one-parameter exponential family as given in definition 3.1 and let TT be the natural statistic. Then Tn=∑i=1nT⁢(Xi)T_{n}=\sum_{i=1}^{n}T(X_{i}) is a sufficient statistic for θ\theta.

For a kk-parameter exponential family as given in definition 3.6, the vector (∑iT1⁢(Xi),…,∑iTk⁢(Xi))\bigl{(}\sum_{i}T_{1}(X_{i}),\dots,\sum_{i}T_{k}(X_{i})\bigr{)} of summed natural statistics is sufficient for the parameter vector.

Proof.

From lemma 3.5 we know that the joint density of the sample is

f⁢(x;θ)=(∏i=1nh⁢(xi))⁢exp⁡(η⁢(θ)⁢∑i=1nT⁢(xi)−n⁢B⁢(θ)).f(x;\theta)=\Bigl{(}\prod_{i=1}^{n}h(x_{i})\Bigr{)}\exp\Bigl{(}\eta(\theta)% \sum_{i=1}^{n}T(x_{i})-nB(\theta)\Bigr{)}.

Thus, we can write the joint density in the form (4.1) with the product ∏ih⁢(xi)\prod_{i}h(x_{i}) in the role of h⁢(x)h(x) and with g⁢(t;θ)=exp⁡(η⁢(θ)⁢t−n⁢B⁢(θ))g(t;\theta)=\exp\bigl{(}\eta(\theta)t-nB(\theta)\bigr{)}. Consequently, TnT_{n} is sufficient by proposition 4.3. A very similar argument gives the proof for kk-parameter exponential families. ∎

Example 4.6.

Let X1,…,XnX_{1},\dots,X_{n} be i.i.d. Poisson with parameter θ>0\theta>0. The joint probability weights are given by

f⁢(x;θ)=∏i=1nθxixi!⁢e−θ=θ∑ixi⁢e−n⁢θ⋅1∏ixi!,f(x;\theta)=\prod_{i=1}^{n}\frac{\theta^{x_{i}}}{x_{i}!}\,e^{-\theta}=\theta^{% \sum_{i}x_{i}}\,e^{-n\theta}\cdot\frac{1}{\prod_{i}x_{i}!},

and thus the sum T=∑iXiT=\sum_{i}X_{i} is sufficient for θ\theta, with g⁢(t;θ)=θt⁢e−n⁢θg(t;\theta)=\theta^{t}e^{-n\theta} and h⁢(x)=1/∏ixi!h(x)=1/\prod_{i}x_{i}!.

Example 4.7.

Let X1,…,Xn∼N⁢(μ,σ2)X_{1},\dots,X_{n}\sim N(\mu,\sigma^{2}) be i.i.d. with both parameters unknown. Example 3.7 identifies the natural statistics as xx and x2x^{2}, and thus by corollary 4.5 the pair T=(∑iXi,∑iXi2)T=\bigl{(}\sum_{i}X_{i},\sum_{i}X_{i}^{2}\bigr{)} is sufficient for (μ,σ2)(\mu,\sigma^{2}). Since ∑i(xi−x¯)2=∑ixi2−n⁢x¯2\sum_{i}(x_{i}-\bar{x})^{2}=\sum_{i}x_{i}^{2}-n\bar{x}^{2}, the pair (X¯,S2)(\bar{X},S^{2}) maps to TT one-to-one and thus is also sufficient. This is the pair of statistics on which the maximum likelihood estimator from example 1.4 is based; the factorisation is worked out in exercise 4.4.

4.4 The Sample Maximum and Minimum

Example 4.4 shows that a sufficient statistic need not be a sum. To find the bias or the mean squared error of the sample maximum we need its distribution, which the following result gives for the maximum and minimum of an i.i.d. sample.

Proposition 4.8.

Let X1,…,XnX_{1},\dots,X_{n} be i.i.d. with distribution function FF and density ff. Furthermore, let X(n)=maxi⁡XiX_{(n)}=\max_{i}X_{i} and X(1)=mini⁡XiX_{(1)}=\min_{i}X_{i}. Then the random variables X(n)X_{(n)} and X(1)X_{(1)} have densities

f(n)⁢(y)=n⁢F⁢(y)n−1⁢f⁢(y)andf(1)⁢(y)=n⁢(1−F⁢(y))n−1⁢f⁢(y).f_{(n)}(y)=n\,F(y)^{n-1}f(y)\qquad\text{and}\qquad f_{(1)}(y)=n\,\bigl{(}1-F(y% )\bigr{)}^{n-1}f(y).
Proof.

The maximum is at most yy, if and only if all observations are at most yy. Using independence we get

ℙ⁢(X(n)≤y)=ℙ⁢(X1≤y,…,Xn≤y)=∏i=1nℙ⁢(Xi≤y)=F⁢(y)n.\mathbb{P}(X_{(n)}\leq y)=\mathbb{P}(X_{1}\leq y,\dots,X_{n}\leq y)=\prod_{i=1% }^{n}\mathbb{P}(X_{i}\leq y)=F(y)^{n}.

Using the chain rule for differentiation with respect to yy, we find that the maximum has density n⁢F⁢(y)n−1⁢f⁢(y)nF(y)^{n-1}f(y). Similarly, the minimum is strictly greater than yy, if and only if all observations are strictly greater than yy. Thus we get

ℙ⁢(X(1)≤y)=1−ℙ⁢(X1>y,…,Xn>y)=1−(1−F⁢(y))n.\mathbb{P}(X_{(1)}\leq y)=1-\mathbb{P}(X_{1}>y,\dots,X_{n}>y)=1-\bigl{(}1-F(y)% \bigr{)}^{n}.

Using the chain rule for differentiation we find n⁢(1−F⁢(y))n−1⁢f⁢(y)n\bigl{(}1-F(y)\bigr{)}^{n-1}f(y). This completes the proof. ∎

Example 4.9.

Let X1,…,Xn∼Uniform⁢(0,θ)X_{1},\dots,X_{n}\sim\text{Uniform}(0,\theta) be i.i.d., as in example 4.4. The distribution function is F⁢(y)=y/θF(y)=y/\theta for 0≤y≤θ0\leq y\leq\theta, and the density is f⁢(y)=1/θf(y)=1/\theta on [0,θ][0,\theta]. By proposition 4.8 the sample maximum has density

f(n)⁢(y)=n⁢(yθ)n−1⁢1θ=n⁢yn−1θn,0≤y≤θ,f_{(n)}(y)=n\Bigl{(}\frac{y}{\theta}\Bigr{)}^{n-1}\frac{1}{\theta}=\frac{n\,y^% {n-1}}{\theta^{n}},\qquad 0\leq y\leq\theta,

and f(n)⁢(y)=0f_{(n)}(y)=0 outside this interval. This is the density supplied without proof in exercise 2.2, from which we computed 𝔼θ⁢(X(n))=n⁢θ/(n+1)\mathbb{E}_{\theta}(X_{(n)})=n\theta/(n+1) there. The support of the maximum moves with θ\theta, as the support of a single observation does.

4.5 Minimal Sufficiency and Completeness

As we have seen in section 4.1, the whole sample is always sufficient. For an i.i.d. sample, the vector of ordered observations is also sufficient, since the joint density does not change when the xix_{i} are interchanged. The aim of this section is to characterise the statistic which allows us to reduce the data as much as possible, while still retaining all the information.

Definition 4.10.

A sufficient statistic TT is minimal sufficient for θ\theta, if for every sufficient statistic SS there is a function φ\varphi such that T=φ⁢(S)T=\varphi(S).

A minimal sufficient statistic can thus be computed from every other sufficient statistic. The definition is awkward to check directly, because it refers to all sufficient statistics at once; the following criterion instead compares the likelihood functions of two data sets. In the criterion we write

𝒳︀={x|f⁢(x;θ)>0⁢ for some ⁢θ∈Θ}\mathcal{X}=\bigl{\{}\,x\bigm{|}f(x;\theta)>0\text{ for some }\theta\in\Theta% \,\bigr{\}}

for the set of data vectors which can be observed under some parameter value, for the Poisson distribution the vectors of non-negative integers.

Proposition 4.11.

Let TT be a statistic such that for all x,y∈𝒳︀x,y\in\mathcal{X} the following two statements are equivalent:

  1. 1.
    ​

    there is a constant c⁢(x,y)>0c(x,y)>0 such that f⁢(x;θ)=c⁢(x,y)⁢f⁢(y;θ)f(x;\theta)=c(x,y)\,f(y;\theta) for all θ∈Θ\theta\in\Theta;

  2. 2.
    ​

    T⁢(x)=T⁢(y)T(x)=T(y).

Then TT is minimal sufficient for θ\theta.

When both f⁢(x;θ)f(x;\theta) and f⁢(y;θ)f(y;\theta) are positive for all θ\theta, the first statement says that the ratio f⁢(x;θ)/f⁢(y;θ)f(x;\theta)/f(y;\theta) does not depend on θ\theta. We only sketch the proof. For sufficiency, we choose for every value tt of TT a data vector xt∈𝒳︀x_{t}\in\mathcal{X} with T⁢(xt)=tT(x_{t})=t; the first statement then gives the factorisation (4.1) with g⁢(t;θ)=f⁢(xt;θ)g(t;\theta)=f(x_{t};\theta) and h⁢(x)=c⁢(x,xt)h(x)=c(x,x_{t}). For minimality, let SS be sufficient and x,y∈𝒳︀x,y\in\mathcal{X} with S⁢(x)=S⁢(y)S(x)=S(y). The factorisation for SS shows that f⁢(x;θ)f(x;\theta) and f⁢(y;θ)f(y;\theta) are proportional, and the criterion gives T⁢(x)=T⁢(y)T(x)=T(y): the value of TT is determined by the value of SS.

The criterion states that T⁢(x)T(x) determines the likelihood function of the data up to a constant factor, and that two data sets with different values of TT have likelihood functions which are not proportional. We apply the criterion once, to the Poisson sum. The two-parameter normal case is worked out in exercise 4.4.

Example 4.12.

Let X1,…,XnX_{1},\dots,X_{n} be i.i.d. Poisson with parameter θ>0\theta>0, and let T=∑iXiT=\sum_{i}X_{i}. For two vectors xx and yy of non-negative integers, both probability weights are positive and the joint probability weights of example 4.6 give

f⁢(x;θ)f⁢(y;θ)=θ∑ixi⁢e−n⁢θ/∏ixi!θ∑iyi⁢e−n⁢θ/∏iyi!=θ∑ixi−∑iyi⁢∏iyi!∏ixi!.\frac{f(x;\theta)}{f(y;\theta)}=\frac{\theta^{\sum_{i}x_{i}}e^{-n\theta}/\prod% _{i}x_{i}!}{\theta^{\sum_{i}y_{i}}e^{-n\theta}/\prod_{i}y_{i}!}=\theta^{\sum_{% i}x_{i}-\sum_{i}y_{i}}\,\frac{\prod_{i}y_{i}!}{\prod_{i}x_{i}!}.

If ∑ixi=∑iyi\sum_{i}x_{i}=\sum_{i}y_{i}, the power of θ\theta disappears and the ratio is a positive constant. If the sums differ by k≠0k\neq 0, the ratio contains the factor θk\theta^{k}, which is not constant as θ\theta ranges over (0,∞)(0,\infty). Thus the ratio is free of θ\theta if and only if ∑ixi=∑iyi\sum_{i}x_{i}=\sum_{i}y_{i}, and TT is minimal sufficient by proposition 4.11.

For the results of lecture 6 we will need one more property of a statistic, concerning functions of the statistic which are unbiased estimators for zero.

Definition 4.13.

A statistic TT is complete, if for every function ww such that w⁢(T)w(T) has finite mean under ℙθ\mathbb{P}_{\theta} for all θ∈Θ\theta\in\Theta, the condition 𝔼θ⁢(w⁢(T))=0\mathbb{E}_{\theta}\bigl{(}w(T)\bigr{)}=0 for all θ∈Θ\theta\in\Theta implies ℙθ⁢(w⁢(T)=0)=1\mathbb{P}_{\theta}\bigl{(}w(T)=0\bigr{)}=1 for all θ∈Θ\theta\in\Theta.

This means that a function of a complete statistic which has expectation zero for all parameter values is itself zero with probability one. The condition is violated for statistics which do not reduce the data enough: in exercise 4.6 we will see that the whole Bernoulli sample is sufficient, but not complete, whereas the total ∑iXi\sum_{i}X_{i} is complete by proposition 6.5 in lecture 6. Completeness is a separate property from minimal sufficiency: a minimal sufficient statistic need not be complete. The property matters because two unbiased estimators for the same quantity which are both functions of a complete statistic agree with probability one. In lecture 6 we will use this uniqueness to turn the Rao–Blackwell improvement into an optimality result.

Summary.

    ​

    A statistic TT is sufficient for θ\theta, if the conditional distribution of the data given TT does not depend on θ\theta: the data can be reduced to TT without losing information about θ\theta.
