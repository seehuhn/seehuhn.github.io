Lecture 21 EM in R

In lecture 19 the EM algorithm was introduced, and in lecture 20 the ascent property was proved. In example 19.1 the E and M steps were derived for a two-component normal mixture. In this lecture we will type the two steps into R functions, check the functions against the hand computation of exercise 20.2, and then run the functions on a simulated sample of size 200200. We will conclude by considering the problem of label switching and the effect of a bad start. The written reference for this session is appendix B.

21.1 The E and M Steps as R Functions

Throughout, the parameter is the vector θ=(π,μ1,μ2)\theta=(\pi,\mu_{1},\mu_{2}) and the common standard deviation σ\sigma is known. The E step of example 19.1 computes the responsibilities γi,k\gamma_{i,k} and the M step computes the updates (19.1). Both steps need only vector arithmetic and the normal density, which the command dnorm can be used to compute. To check the iteration, we also compute the observed-data log-likelihood ℓ\ell, which by proposition 20.2 cannot decrease from one iteration to the next.

resp <- function(x, theta, sigma) {
a <- theta[1] * dnorm(x, mean = theta[2], sd = sigma)
b <- (1 - theta[1]) * dnorm(x, mean = theta[3], sd = sigma)
a / (a + b)
}
mstep <- function(x, gamma) {
c(mean(gamma),
sum(gamma * x) / sum(gamma),
sum((1 - gamma) * x) / sum(1 - gamma))
}
loglik <- function(x, theta, sigma) {
sum(log(theta[1] * dnorm(x, mean = theta[2], sd = sigma) +
(1 - theta[1]) * dnorm(x, mean = theta[3], sd = sigma)))
}

We first test our functions on the data from exercise 20.2. For this we use the five observations x=(0,1,5,6,7)x=(0,1,5,6,7) where σ=1\sigma=1 and the initial value is θ0=(1/2,2,4)\theta_{0}=(1/2,2,4). The results of one iteration of the algorithm are then compared to the responsibilities and the iterate θ1\theta_{1}, and to the two values of the log-likelihood computed by hand.

x <- c(0, 1, 5, 6, 7)
theta <- c(0.5, 2, 4)
gamma <- resp(x, theta, 1)
round(gamma, 4)
theta1 <- mstep(x, gamma)

21.2 A Larger Sample

The two groups in the five observations of exercise 20.2 are far apart, and the iteration converges to (0.4,0.5,6.0)(0.4,0.5,6.0), as stated in section 20.2. Here we simulate a sample where the groups overlap. We can simulate such a sample by first randomly choosing a group, using rbinom to get Zi=1Z_{i}=1 with probability π=0.3\pi=0.3. For the other group R gives the value 0 instead of 22, and thus z == 0 marks group 2. We then simulate the measurements from the normal distribution corresponding to the group, i.e. with means 0 and 33 and σ=1\sigma=1. The command ifelse can be used to choose the correct mean for each observation. The box below contains the complete script for simulation and EM iteration, with lines shuffled (except for the body of the loop). Before you can run the script, you have to arrange these lines into a working script. Following the stopping rule of section 20.2, the command break ends the loop as soon as the log-likelihood increases by less than 10−810^{-8}. The vector ll stores the log-likelihood after each iteration, with the initial value at position 11, and grows by one entry per iteration.

theta <- c(0.5, q[1], q[2])
for (k in 1:1000) {
theta <- mstep(x, resp(x, theta, 1))
ll[k + 1] <- loglik(x, theta, 1)
if (ll[k + 1] - ll[k] < 1e-8) break
}
z <- rbinom(n, size = 1, prob = 0.3)
n <- 200
q <- quantile(x, c(0.25, 0.75), names = FALSE)
set.seed(2026)
ll <- loglik(x, theta, 1)
x <- rnorm(n, mean = ifelse(z == 1, 0, 3), sd = 1)

The rule is the one from lecture 9: each line must come after all lines on which it depends. As in that lecture, several orders satisfy the rule. One of them is seed, n, z and x, quartiles q, start value, first entry of ll, and then the loop; the seed and n can also be swapped. The start values put the weight at 1/21/2 and the two means at the two quartiles, which is a cheap way to split the sample into two groups. After the loop, the variable k keeps the number of the last iteration. Before you look at the output, answer two questions. The fixed point θ^=(0.240,0.220,3.076)\hat{\theta}=(0.240,0.220,3.076) is close to the proportion 48/200=0.2448/200=0.24 of group-1 observations which were actually drawn, rather than to π=0.3\pi=0.3, and it recovers the two means to within about two tenths. By proposition 20.3 the fixed point is a root of the likelihood equation. The command diff can be used to compute the differences of consecutive entries of a vector, and thus d holds the increases of the log-likelihood in the 2828 iterations. The last two lines of the output show the first seven and seven of the last increases. They are positive, as proposition 20.2 guarantees, but they are not equal. Towards the end, each increase is about 0.40.4 times the previous one, for example 3.3⋅10−63.3\cdot 10^{-6}, then 1.3⋅10−61.3\cdot 10^{-6} and 5.4⋅10−75.4\cdot 10^{-7}. This is the geometric convergence mentioned in section 20.2. Since 0.66⋅0.4200.66\cdot 0.4^{20} is approximately 7⋅10−97\cdot 10^{-9}, at this rate about 2020 further iterations are needed to reduce the increase from 0.660.66 in the seventh iteration to below the tolerance 10−810^{-8}, which explains the total of 2828 iterations. The factor 0.40.4 depends on the data, and the take-home task below shows what happens when the groups overlap more.

At the fixed point the responsibility of group 1 is a decreasing function of xx which equals 1/21/2 where π⁢φσ⁢(x−μ1)=(1−π)⁢φσ⁢(x−μ2)\pi\varphi_{\sigma}(x-\mu_{1})=(1-\pi)\varphi_{\sigma}(x-\mu_{2}). The crossing happens at 1.2441.244, well below the midpoint 1.6481.648, since the weights are unequal: an observation which is half-way between the means has three times the probability of being from the larger group. The filled and open circles give the true group of each observation, which is not known to EM. The responsibilities agree with the truth when the observations are far away from the crossing point, but between 0.70.7 and 1.61.6 both types of observations can be found and the group cannot be decided. 21.3 Label Switching and a Bad Start

Section 20.2 discusses label switching and the danger of a poor start. In the script R/S21-starts.R the loop is packaged as a function em, which is then run on our sample from three starts: the quartile start, the same start with the two means swapped, and the start (1/2,3,3)(1/2,3,3) with both means equal. Before you look at table 21.1, predict where the start with the swapped means ends up, and what happens to the responsibilities, and thus to the next update, when μ1=μ2\mu_{1}=\mu_{2}.

The start with swapped means ends in the mirror image (0.760,3.076,0.220)(0.760,3.076,0.220) after the same 2828 iterations and with the same log-likelihood. Both parameter values give the same density, so the model is not identifiable in the sense of definition 4.10, and the labelling in the start determines which of the two maxima we reach. When μ1=μ2\mu_{1}=\mu_{2}, the two normal densities in the responsibility cancel, all γi\gamma_{i} are equal to π\pi, and the M step sets both means equal to the sample mean while leaving the weight unchanged. The next step changes nothing, and the loop stops after two iterations at (1/2,2.3915,2.3915)(1/2,2.3915,2.3915), effectively a single normal distribution, with a log-likelihood 6767 below the maximum. This resting point is a root of the likelihood equation by proposition 20.3. Since the density does not depend on π\pi when μ1=μ2\mu_{1}=\mu_{2}, every point (π,x¯,x¯)(\pi,\bar{x},\bar{x}) is such a root, and the weight 1/21/2 is simply the weight of the start.

The resting point is not a local maximum. The log-likelihood at the nearby start (1/2,2.39,2.41)(1/2,2.39,2.41) is already equal to −421.800-421.800. This is slightly above the value −421.807-421.807 at the resting point, and figure 21.2 shows that EM started there climbs all the way to the maximum. Neither is it a local minimum, since among the points with μ1=μ2\mu_{1}=\mu_{2} the log-likelihood is largest at the sample mean. The resting point is thus a saddle point, and EM cannot tell a saddle point apart from a maximum. The figure also shows that near the saddle point the log-likelihood increases only slowly at first: the first iteration from the nearby start gains only 0.070.07. With a coarse tolerance such as 0.10.1, the loop would have stopped there, far away from the maximum.

21.4 A Task to Take Home

The published scripts of this lecture can be used as a starting point for the following task. Choose a weight π\pi between 0.20.2 and 0.50.5 and two means which are two to three units apart. Using your student ID as the seed, simulate a sample of size n=300n=300 from the mixture with σ=1\sigma=1 and run the EM algorithm from the quartile start. The EM algorithm does not provide standard errors. To obtain them, use optim with hessian = TRUE to minimise the negative of loglik, starting from the fixed point, as in lecture 18; the script R/S21-mixture.R contains the necessary command. Report each estimate with its standard error. Then repeat the task with the two means only one unit apart. How many iterations does the loop need now, and what happens to the standard errors? If the loop runs through all 10001000 iterations, the stopping rule was never met and the result is not a fixed point, so you should say so in your answer.

Typing the commands yourself is an important step towards understanding how the R scripts work. Before the next session, please type in the commands from this session, and check that you get the same results as shown in the text.

  • •

    The responsibility of group 1 is a decreasing S-shaped function of xx. The function crosses 1/21/2 below the midpoint of the means when group 1 is the smaller group. Close to the crossing point it is no longer possible to decide which group an observation belongs to.

  • •
    ​

    If the labels are swapped before starting the EM algorithm, the algorithm converges to the mirror-image maximum with the same log-likelihood. If the two means are equal at the start, the EM algorithm stops at a saddle point immediately, i.e. at a root of the likelihood equation which is not a maximum. To avoid this, the EM algorithm should be started with different values and the best of the resulting runs should be chosen, based on the log-likelihood of the observed data.
